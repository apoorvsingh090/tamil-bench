# TPL-Bench — LLM-judge rubric (Tamil)

`surukkam` / `eluthu` / `grounded-long` இவற்றின் அதிகாரப்பூர்வ மதிப்பெண் LLM-judge + மனித தணிக்கையால் முடிவாகிறது.
`src/evaluate.py`-இன் token-F1 தகவலுக்கு மட்டும்.

## Judge settings (v0.1.0, seed)

* Judge model: வலுவான பன்மொழி மாதிரி எதுவும் (எ.கா. GPT-4o / Gemma-3-27b-it).
  கட்டுரை/பட்டியலில் judge பெயர் + version + temperature குறிப்பிடுக.
* Decoding: `temperature=0.0`, அதிகம் 512 tokens, JSON-only output.
* Calibration: ஒவ்வொரு பிரிவிலும் 20 மனித மதிப்பீட்டு மாதிரிகளில் Cohen-kappa ≥ 0.6 இலக்கு;
  5% மனித தணிக்கை கட்டாயம் (C1/eluthu-வில் 10% பரிந்துரை).

## Scoring (ஒவ்வொன்றும் 1-5)

* **சரி (sari)** — இலக்கணம், எழுத்து சரி.
* **தெளிவு (thelivu)** — கருத்து/உண்மை தெளிவு, தலைப்பில் நிலை, கற்பனை இல்லை.
* **அமைப்பு (amaippu)** — பத்தி வரிசை, ஓட்டம், வடிவம் (கடிதம்/அறிவிப்பு/உரையாடல்).
* **பொருத்தம் (porutham)** — சொல் வரம்பு, நோக்கம், நடை (முறைமை/பேச்சு/Tanglish) பொருத்தம்.

## Judge prompt (copy-paste)

```
நீங்கள் TPL-Bench-இன் நடுநிலை தேர்வாளர். JSON-ஆக மட்டும் மதிப்பெண் தருக.
பிரிவு: {track} | நிலை: {level}
அறிவுறுத்தல்: {prompt_ta}
பத்தி/பகுதிகள்: {passage_ta}
மாதிரி பதில்: {prediction}
குறிப்பு பதில் (இருந்தால்): {answer}
ரூப்ரிக்: சரி, தெளிவு, அமைப்பு, பொருத்தம் — ஒவ்வொன்றும் 1-5.
தண்டம்: உண்மை மாற்றம்/புது செய்திக்கு தெளிவு ≤2; மேற்கோள் இல்லாத grounded பதிலுக்கு பொருத்தம் ≤2;
சொல் வரம்பு மீறலுக்கு பொருத்தம் -1.
JSON: {"sari": 1-5, "thelivu": 1-5, "amaippu": 1-5, "porutham": 1-5, "kurippu": "ஒரு வாக்கியம்"}
```

## Bias controls

* Verbosity: நீளத்தை தானாக குணமாக கருத வேண்டாம்; சுருக்க-சரி > நீள-தவறு.
* Self-preference: judge தன் மாதிரி குடும்பம் அறியாமல்; blind ID-ஆல் மதிப்பிடுக.
* Register: செந்தமிழ்/பேச்சு/Tanglish-ஐ பொருத்தத்தால் மதிப்பிடுக, தனி விருப்பால் அல்ல.
* Position: இரட்டை ஒப்பீட்டில் வரிசை மாற்றி மீண்டும் செய்க.
